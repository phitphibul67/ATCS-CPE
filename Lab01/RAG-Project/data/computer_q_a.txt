Q: CPU คืออะไร และทำหน้าที่อะไรในคอมพิวเตอร์?
A: CPU (Central Processing Unit) คือหน่วยประมวลผลกลาง ทำหน้าที่เปรียบเสมือนสมองของคอมพิวเตอร์ คอยคำนวณ ประมวลผลคำสั่ง และควบคุมการทำงานของอุปกรณ์ต่างๆ ในระบบ

[หมวด: Hardware]
Q: RAM คืออะไร และแตกต่างจาก Hard Disk อย่างไร?
A: RAM เป็นหน่วยความจำหลักแบบชั่วคราว มีความเร็วสูง ใช้เก็บข้อมูลขณะโปรแกรมกำลังทำงาน ข้อมูลจะหายไปเมื่อปิดเครื่อง ส่วน Hard Disk เป็นหน่วยความจำถาวร ใช้บันทึกข้อมูลยาวนานแม้ปิดเครื่อง

[หมวด: Hardware]
Q: GPU หรือการ์ดแสดงผล มีหน้าที่อะไร?
A: GPU (Graphics Processing Unit) คือหน่วยประมวลผลกราฟิก ทำหน้าที่ประมวลผลภาพ วิดีโอ กราฟิก 3 มิติ และงานคำนวณที่ต้องทำพร้อมกันจำนวนมาก ช่วยลดภาระของ CPU

[หมวด: Hardware]
Q: SSD กับ HDD ต่างกันอย่างไร ควรเลือกใช้แบบไหน?
A: SSD มีความเร็วอ่านเขียนสูงกว่า HDD มาก ทนทานต่อแรงกระแทก เหมาะสำหรับลงระบบปฏิบัติการและโปรแกรม ส่วน HDD มีราคาต่อความจุถูกกว่า เหมาะกับการเก็บไฟล์ข้อมูลขนาดใหญ่

[หมวด: Hardware]
Q: Motherboard คืออะไร?
A: Motherboard (เมนบอร์ด) คือแผงวงจรหลักของคอมพิวเตอร์ ทำหน้าที่เชื่อมต่ออุปกรณ์ฮาร์ดแวร์ทุกชิ้น เช่น CPU, RAM, การ์ดจอ และไดรฟ์จัดเก็บข้อมูล ให้สามารถทำงานร่วมกันได้

[หมวด: Hardware]
Q: Power Supply (PSU) ทำหน้าที่อะไร?
A: Power Supply ทำหน้าที่แปลงไฟฟ้ากระแสสลับ (AC) จากปลั๊กไฟบ้าน ให้เป็นไฟฟ้ากระแสตรง (DC) ที่เหมาะสมเพื่อจ่ายไฟให้แก่อุปกรณ์ต่างๆ ภายในเครื่องคอมพิวเตอร์

[หมวด: Hardware]
Q: คอมพิวเตอร์เปิดไม่ติด มีเสียงร้องตี๊ดยาวๆ เกิดจากอะไร?
A: อาการนี้มักเกิดจาก RAM หรือการ์ดจอหลวมหรือมีปัญหา วิธีแก้เบื้องต้นคือถอดปลั๊ก ปิดเครื่อง แล้วถอด RAM ออกมาใช้ยางลบสะอาดขัดแถบทองเหลืองก่อนเสียบกลับให้แน่น

[หมวด: Hardware]
Q: Thermal Paste (ซิลิโคนระบายความร้อน) มีความสำคัญอย่างไร?
A: ซิลิโคนเป็นตัวประสานเพื่อช่วยส่งผ่านความร้อนจากหน้าสัมผัสของ CPU ไปยังตัวระบายความร้อน (Heatsink) ช่วยลดอุณหภูมิและป้องกันไม่ให้ CPU ร้อนเกินไปจนเสียหาย

[หมวด: Hardware]
Q: พอร์ต USB Type-C ดีกว่า USB Type-A อย่างไร?
A: USB Type-C สามารถเสียบได้ทั้งสองด้าน รองรับความเร็วในการส่งถ่ายข้อมูลสูงกว่า จ่ายไฟได้มากกว่า (Power Delivery) และสามารถส่งสัญญาณภาพ/เสียงผ่านพอร์ตเดียวได้

[หมวด: Hardware]
Q: UPS (เครื่องสำรองไฟ) จำเป็นหรือไม่?
A: จำเป็นสำหรับพื้นที่ไฟตกหรือไฟดับบ่อย UPS ช่วยจ่ายไฟสำรองให้มีเวลาเซฟงานและปิดเครื่องอย่างถูกต้อง ป้องกันความเสียหายต่อฮาร์ดแวร์และข้อมูลสูญหาย

[หมวด: Hardware]
Q: Monitor มี Refresh Rate (Hz) สูงๆ ดีอย่างไร?
A: Refresh Rate แสดงจำนวนครั้งที่หน้าจอกระพริบภาพในหนึ่งวินาที ยิ่ง Hz สูง ภาพเคลื่อนไหวจะยิ่งลื่นไหล สบายตา และลดอาการภาพฉีกขาด เหมาะสำหรับการเล่นเกมและงานวิดีโอ

[หมวด: Hardware]
Q: M.2 NVMe SSD ต่างจาก M.2 SATA อย่างไร?
A: M.2 NVMe เชื่อมต่อผ่านบัส PCIe มีความเร็วในการรับส่งข้อมูลสูงกว่า M.2 SATA ซึ่งใช้อินเทอร์เฟซแบบ SATA ดั้งเดิมอยู่หลายเท่า

[หมวด: Hardware]
Q: สาเหตุที่คอมพิวเตอร์ดับเองกลางคันเกิดจากอะไรได้บ้าง?
A: เกิดจาก CPU ร้อนเกินไปจนระบบสั่งตัดไฟ พาวเวอร์ซัพพลาย (PSU) จ่ายไฟไม่พอหรือเสื่อมสภาพ พัดลมระบายความร้อนเสีย หรือมีปัญหาระบบไฟฟ้าภายในบ้าน

[หมวด: Hardware]
Q: คอมพิวเตอร์ช้าลงเมื่อใช้งานไปนานๆ เกิดจากอะไร?
A: อาจเกิดจากขยะในดิสก์มากเกินไป RAM ไม่พอ ฮาร์ดดิสก์เริ่มเสื่อมสภาพ ฝุ่นจับตัวระบายความร้อนทำให้เครื่องร้อน หรือมีโปรแกรมแอบทำงานอยู่เบื้องหลังจำนวนมาก

[หมวด: Hardware]
Q: BIOS / UEFI คืออะไร?
A: คือเฟิร์มแวร์ที่ฝังอยู่ในเมนบอร์ด ทำหน้าที่ตรวจสอบและเริ่มต้นการทำงานของอุปกรณ์ฮาร์ดแวร์ทั้งหมด ก่อนที่จะโหลดระบบปฏิบัติการ (OS) ขึ้นมาใช้งาน

[หมวด: Software]
Q: Operating System (OS) คืออะไร?
A: ระบบปฏิบัติการ คือซอฟต์แวร์ระบบที่ทำหน้าที่เป็นตัวกลางในการจัดการทรัพยากรฮาร์ดแวร์ และอำนวยความสะดวกให้ผู้ใช้สามารถรันแอปพลิเคชันต่างๆ ได้ เช่น Windows, macOS, Linux

[หมวด: Software]
Q: หน้าจอฟ้า (BSOD) ใน Windows เกิดจากอะไร?
A: เกิดจากข้อผิดพลาดร้ายแรงของระบบ เช่น ไดรเวอร์อุปกรณ์มีปัญหา ไฟล์ระบบเสียหาย อุปกรณ์ฮาร์ดแวร์ชำรุด (โดยเฉพาะ RAM) หรือการอัปเดตระบบไม่สมบูรณ์

[หมวด: Software]
Q: Open Source Software คืออะไร?
A: คือซอฟต์แวร์ที่เปิดเผยซอร์สโค้ด อนุญาตให้ทุกคนนำไปใช้งาน แก้ไข พัฒนาต่อ และเผยแพร่ได้อย่างเสรี เช่น Linux, Python, Blender

[หมวด: Software]
Q: Device Driver คืออะไร ทำไมต้องอัปเดต?
A: คือโปรแกรมย่อยที่ช่วยให้ OS สื่อสารกับฮาร์ดแวร์ได้อย่างถูกต้อง การอัปเดตจะช่วยเพิ่มประสิทธิภาพ แก้ไขบั๊ก และเพิ่มการรองรับฟีเจอร์ใหม่ๆ

[หมวด: Software]
Q: ความแตกต่างระหว่าง 32-bit และ 64-bit OS คืออะไร?
A: 64-bit สามารถรองรับการประมวลผลข้อมูลปริมาณมากและรองรับ RAM ได้มากกว่า 4GB (เทียบกับ 32-bit ที่จำกัด RAM ไว้ที่ประมาณ 4GB เท่านั้น)

[หมวด: Software]
Q: โปรแกรมประเภท Portable ต่างจากโปรแกรมปกติอย่างไร?
A: โปรแกรม Portable สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งลงเครื่อง ไม่มีการบันทึกไฟล์ลงใน System Registry สามารถใส่ใน Flash Drive ไปใช้เครื่องอื่นได้สะดวก

[หมวด: Software]
Q: Virtual Machine (VM) คืออะไร?
A: คือการจำลองสภาพแวดล้อมคอมพิวเตอร์เสมือนขึ้นมาภายในเครื่องจริง ทำให้สามารถรันระบบปฏิบัติการอื่นขนานไปกับ OS หลักได้ เช่น รัน Linux บน Windows

[หมวด: Software]
Q: Task Manager ใน Windows มีไว้ทำอะไร?
A: เป็นเครื่องมือสำหรับตรวจสอบการใช้ทรัพยากร (CPU, RAM, Disk, Network) การทำงานของกระบวนการต่างๆ (Processes) และใช้บังคับปิดโปรแกรมที่ไม่ตอบสนอง (End Task)

[หมวด: Software]
Q: Safe Mode ใน Windows คืออะไร?
A: คือโหมดการทำงานพิเศษที่โหลดเฉพาะไฟล์และไดรเวอร์พื้นฐานที่จำเป็นเท่านั้น เหมาะสำหรับใช้ตรวจหาสาเหตุและแก้ไขปัญหาเมื่อระบบปกติมีปัญหาหรือติดไวรัส

[หมวด: Software]
Q: การ Defragment ฮาร์ดดิสก์ ช่วยอะไร?
A: ช่วยเรียบเรียงจัดหมวดหมู่ไฟล์ที่กระจายอยู่บนจานแม่เหล็กให้อยู่ต่อเนื่องกัน ทำให้หัวอ่านทำงานน้อยลงและโหลดข้อมูลได้เร็วขึ้น (หมายเหตุ: ไม่ควรทำกับ SSD)

[หมวด: Software]
Q: Cache Memory ทำหน้าที่อะไร?
A: เป็นหน่วยความจำความเร็วสูงมากๆ ที่อยู่ใน CPU ใช้เก็บข้อมูลที่เรียกใช้บ่อยๆ เพื่อให้ประมวลผลได้รวดเร็วยิ่งขึ้นโดยไม่ต้องไปดึงข้อมูลจาก RAM

[หมวด: Software]
Q: File System แบบ NTFS, FAT32 และ exFAT ต่างกันอย่างไร?
A: FAT32 รองรับเกือบทุกอุปกรณ์แต่จำกัดขนาดไฟล์ไม่เกิน 4GB, NTFS รองรับไฟล์ขนาดใหญ่และระบบความปลอดภัยสูง (ใช้กับ Windows), exFAT เหมาะกับ Flash Drive ที่ต้องการใส่ไฟล์ใหญ่และใช้ได้ทั้ง Mac/Windows

[หมวด: Software]
Q: การตั้งค่า Factory Reset ต่างจากการลง OS ใหม่ (Clean Install) อย่างไร?
A: Factory Reset คือการคืนค่าระบบเดิมจากโรงงาน อาจยังมีไฟล์ขยะหรือ Bloatware ค้างอยู่ ส่วน Clean Install คือการลบไดรฟ์แล้วติดตั้ง OS ใหม่ทั้งหมด ซึ่งจะได้ระบบที่สะอาดที่สุด

[หมวด: Software]
Q: API ย่อมาจากอะไรและมีประโยชน์อย่างไร?
A: API (Application Programming Interface) คือชุดคำสั่งที่ช่วยให้ซอฟต์แวร์หรือแอปพลิเคชันต่างระบบสามารถเชื่อมต่อและแลกเปลี่ยนข้อมูลกันได้อย่างเป็นมาตรฐาน

[หมวด: Software]
Q: ซอฟต์แวร์แบบ SaaS คืออะไร?
A: SaaS (Software as a Service) คือการให้บริการซอฟต์แวร์ผ่านอินเทอร์เน็ตแบบสมัครสมาชิก โดยผู้ใช้ไม่จำเป็นต้องติดตั้งโปรแกรมลงเครื่อง เช่น Google Workspace, Microsoft 365

[หมวด: Network]
Q: IP Address คืออะไร?
A: คือหมายเลขอ้างอิงประจำอุปกรณ์ที่เชื่อมต่ออยู่ในระบบเครือข่าย ทำหน้าที่ระบุตัวตนและตำแหน่งเพื่อให้ส่งข้อมูลหากันได้อย่างถูกต้อง

[หมวด: Network]
Q: IPv4 กับ IPv6 ต่างกันอย่างไร?
A: IPv4 ใช้เลข 32-bit (เช่น 192.168.1.1) มีจำนวนชุดจำกัด ส่วน IPv6 ใช้เลข 128-bit รองรับจำนวนอุปกรณ์ได้มหาศาลเพื่อแก้ปัญหา IPv4 หมดลง

[หมวด: Network]
Q: Router ทำหน้าที่อะไร?
A: ทำหน้าที่เป็นตัวกลางในการเชื่อมต่อเครือข่ายต่างระบบเข้าด้วยกัน (เช่น เครือข่ายในบ้านกับอินเทอร์เน็ต) และจัดหาเส้นทางส่งแพ็กเกจข้อมูลที่เหมาะสมที่สุด

[หมวด: Network]
Q: Switch แตกต่างจาก Hub อย่างไร?
A: Switch ส่งข้อมูลเจาะจงไปยังอุปกรณ์ปลายทางที่ต้องการเท่านั้น ส่วน Hub จะส่งข้อมูลกระจายไปยังทุกอุปกรณ์ที่ต่ออยู่ ทำให้เครือข่ายของ Hub เกิดความหนาแน่นและช้ากว่า

[หมวด: Network]
Q: DNS (Domain Name System) คืออะไร?
A: ทำหน้าที่แปลชื่อเว็บไซต์ที่มนุษย์เข้าใจ (เช่น google.com) ให้กลายเป็น IP Address ที่คอมพิวเตอร์เข้าใจ (เช่น 142.250.190.46)

[หมวด: Network]
Q: Wi-Fi 6 ดีกว่า Wi-Fi 5 อย่างไร?
A: Wi-Fi 6 มีความเร็วรับส่งข้อมูลสูงขึ้น รองรับอุปกรณ์เชื่อมต่อพร้อมกันได้จำนวนมากโดยไม่หน่วง ประหยัดพลังงานมากกว่า และลดความล่าช้า (Latency)

[หมวด: Network]
Q: MAC Address คืออะไร?
A: คือหมายเลขประจำตัวทางกายภาพของอุปกรณ์รับส่งสัญญาณเครือข่าย (NIC) ที่ถูกบันทึกมาจากโรงงาน ไม่สามารถเปลี่ยนแปลงได้ (ระบุตัวตนในระดับฮาร์ดแวร์)

[หมวด: Network]
Q: Ping และ Latency คืออะไร?
A: Latency คือระยะเวลาที่ข้อมูลใช้เดินทางจากต้นทางไปปลายทาง มีหน่วยเป็นมิลลิวินาที (ms) ส่วน Ping คือคำสั่งทดสอบค่า Latency และวัดการเชื่อมต่อเครือข่าย

[หมวด: Network]
Q: ความถี่ 2.4 GHz กับ 5 GHz ของ Wi-Fi ต่างกันอย่างไร?
A: 2.4 GHz ส่งสัญญาณได้ไกล ทะลุสิ่งกีดขวางได้ดี แต่ความเร็วต่ำกว่า ส่วน 5 GHz ส่งได้สั้นกว่า ทะลุสิ่งกีดขวางได้น้อย แต่ทำความเร็วได้สูงมากและสัญญาณรบกวนน้อย

[หมวด: Network]
Q: Bandwidth หมายถึงอะไร?
A: หมายถึง ปริมาณข้อมูลสูงสุดที่สามารถส่งผ่านเครือข่ายได้ภายในระยะเวลาที่กำหนด (เปรียบเสมือนขนาดความกว้างของถนน)

[หมวด: Network]
Q: VPN (Virtual Private Network) ทำงานอย่างไร?
A: VPN สร้างอุโมงค์เชื่อมต่อข้อมูลที่เข้ารหัสปลอดภัยระหว่างอุปกรณ์ของคุณกับเซิร์ฟเวอร์ VPN ช่วยซ่อน IP Address จริงและปกป้องข้อมูลจากการถูกดักฟัง

[หมวด: Network]
Q: DHCP Server ทำหน้าที่อะไร?
A: ทำหน้าที่แจกจ่าย IP Address และการตั้งค่าเครือข่ายอื่นๆ ให้แก่อุปกรณ์ที่เข้ามาเชื่อมต่อในระบบเครือข่ายโดยอัตโนมัติ

[หมวด: Network]
Q: Port Number ในระบบ Network มีไว้เพื่ออะไร?
A: ใช้ระบุแอปพลิเคชันหรือบริการปลายทางบนเครื่องคอมพิวเตอร์ เพื่อให้ส่งข้อมูลเข้าออกได้ถูกช่องทาง เช่น Port 80 สำหรับ HTTP และ Port 443 สำหรับ HTTPS

[หมวด: Network]
Q: สายแลน CAT5e กับ CAT6 ต่างกันอย่างไร?
A: CAT6 รองรับแบนด์วิดท์และระดับความเร็วได้สูงกว่า (สูงสุด 10 Gbps ที่ระยะสั้น) และมีการป้องกันสัญญาณรบกวนระหว่างคู่สายได้ดีกว่า CAT5e

[หมวด: Network]
Q: Gateway ในระบบเครือข่ายคืออะไร?
A: คือจุดเชื่อมต่อประตูทางผ่านระหว่างเครือข่ายสองเครือข่ายที่มีโปรโตคอลต่างกัน เช่น เชื่อม LAN ในบ้านออกสู่อินเทอร์เน็ต

[หมวด: Security]
Q: Malware คืออะไร?
A: เป็นคำรวมเรียกซอฟต์แวร์ประสงค์ร้ายทุกชนิดที่สร้างขึ้นมาเพื่อสร้างความเสียหาย ขโมยข้อมูล หรือรบกวนการทำงานของระบบ เช่น ไวรัส, เวิร์ม, ทรจัน, แรนซัมแวร์

[หมวด: Security]
Q: Ransomware (มัลแวร์เรียกค่าไถ่) มีลักษณะการทำงานอย่างไร?
A: จะทำการเข้ารหัสไฟล์ข้อมูลในเครื่องของเหยื่อทำให้เปิดใช้งานไม่ได้ จากนั้นจะแสดงข้อความเรียกเงินค่าไถ่เพื่อแลกกับรหัสปลดล็อกไฟล์

[หมวด: Security]
Q: Phishing คืออะไร และป้องกันได้อย่างไร?
A: คือการหลอกลวงทางออนไลน์ผ่านอีเมลหรือเว็บปลอมเพื่อขโมยข้อมูลสำคัญ ป้องกันโดยตรวจสอบ URL ก่อนกรอกข้อมูล ไม่คลิก Link แปลกปลอม และสังเกตชื่อผู้ส่ง

[หมวด: Security]
Q: Firewall มีหน้าที่อะไร?
A: ทำหน้าที่เป็นกำแพงกรองข้อมูล ตรวจสอบและควบคุมทราฟฟิกเครือข่ายเข้า-ออกตามกฎความปลอดภัย เพื่อป้องกันการบุกรุกจากภายนอก

[หมวด: Security]
Q: Two-Factor Authentication (2FA) คืออะไร?
A: คือการยืนยันตัวตนสองขั้นตอน เช่น ใช้รหัสผ่านร่วมกับ OTP ที่ส่งเข้ามือถือ เพื่อเพิ่มความปลอดภัยแม้ว่ารหัสผ่านจะหลุดไปก็ตาม

[หมวด: Security]
Q: Trojan Horse (มัลแวร์ม้าโทรจัน) คืออะไร?
A: คือโปรแกรมประสงค์ร้ายที่แฝงตัวมาในรูปแบบของโปรแกรมที่ดูน่าเชื่อถือ เมื่อผู้ใช้นำไปติดตั้ง มัลแวร์จะแอบเปิดช่องทางให้ผู้ไม่หวังดีเข้ามาควบคุมเครื่องได้

[หมวด: Security]
Q: Denial of Service (DoS / DDoS) คืออะไร?
A: คือการโจมตีระบบโดยการส่งทราฟฟิกจำนวนมหาศาลเข้าไปพร้อมๆ กัน จนกระทั่งเซิร์ฟเวอร์ทำงานหนักเกินไปและล่ม ไม่สามารถให้บริการผู้ใช้ปกติได้

[หมวด: Security]
Q: การตั้งรหัสผ่านที่ปลอดภัยควรมีลักษณะอย่างไร?
A: ควรมีความยาวอย่างน้อย 12 ตัวอักษร ผสมตัวอักษรใหญ่-เล็ก ตัวเลข และสัญลักษณ์พิเศษ ไม่ใช้วันเกิดหรือคำที่คาดเดาง่าย และไม่ใช้รหัสซ้ำกันในหลายบริการ

[หมวด: Security]
Q: Zero-Day Vulnerability คืออะไร?
A: คือช่องโหว่ทางความปลอดภัยของซอฟต์แวร์ที่พึ่งถูกค้นพบ และยังไม่มีแพตช์ (Patch) แก้ไขจากผู้พัฒนา ทำให้มีความเสี่ยงสูงที่จะถูกโจมตี

[หมวด: Security]
Q: Spyware ทำอะไรกับเครื่องของเรา?
A: แอบแฝงเก็บข้อมูลพฤติกรรมการใช้งาน บันทึกการพิมพ์รหัสผ่าน (Keylogger) หรือขโมยข้อมูลส่วนบุคคลส่งกลับไปให้ผู้โจมตีโดยที่เราไม่รู้ตัว

[หมวด: Security]
Q: HTTPS ต่างจาก HTTP อย่างไร?
A: HTTPS มีการเข้ารหัสข้อมูลที่รับส่งระหว่างเบราว์เซอร์กับเซิร์ฟเวอร์ด้วย SSL/TLS ทำให้ปลอดภัยจากการถูกดักฟังข้อมูล ต่างจาก HTTP ที่ส่งเป็นข้อความธรรมดา

[หมวด: Security]
Q: Social Engineering ในทางความปลอดภัยคอมพิวเตอร์คืออะไร?
A: คือการหลอกลวงโดยใช้จิตวิทยาเล่นกับความโลภ ความกลัว หรือความไว้ใจของมนุษย์ เพื่อหลอกเอาข้อมูลสำคัญ โดยไม่ต้องใช้ทักษะทางเทคนิคขั้นสูง

[หมวด: Security]
Q: Encryption (การเข้ารหัสข้อมูล) คืออะไร?
A: คือการแปลงข้อมูลให้อยู่ในรูปรหัสลับที่ไม่สามารถอ่านได้ ผู้ที่มีกุญแจถอดรหัส (Decryption Key) เท่านั้นจึงจะสามารถเปิดอ่านข้อมูลดั้งเดิมได้

[หมวด: Security]
Q: Antivirus ทำงานอย่างไร?
A: ตรวจหาไฟล์ประสงค์ร้ายโดยเปรียบเทียบกับฐานข้อมูลลายเซ็นไวรัส (Signatures) หรือตรวจจับพฤติกรรมที่น่าสงสัยของโปรแกรมเพื่อบล็อกและกำจัดออกไป

[หมวด: Security]
Q: Man-in-the-Middle Attack (MitM) คืออะไร?
A: คือการที่แฮกเกอร์แอบแทรกตัวอยู่ตรงกลางระหว่างผู้ใช้กับเซิร์ฟเวอร์ เพื่อดักจับ แอบดู หรือเปลี่ยนแปลงข้อมูลที่รับส่งกันโดยที่ทั้งสองฝ่ายไม่รู้ตัว

[หมวด: Cloud & Database]
Q: Cloud Computing คืออะไร?
A: คือบริการให้ใช้ทรัพยากรคอมพิวเตอร์ (เช่น เซิร์ฟเวอร์, พื้นที่เก็บข้อมูล, ฐานข้อมูล, ระบบเครือข่าย) ผ่านอินเทอร์เน็ต โดยคิดค่าบริการตามการใช้งานจริง

[หมวด: Cloud & Database]
Q: ความแตกต่างระหว่าง IaaS, PaaS และ SaaS คืออะไร?
A: IaaS ให้บริการโครงสร้างพื้นฐาน (ฮาร์ดแวร์/VM), PaaS ให้บริการแพลตฟอร์มพร้อมสภาพแวดล้อมสำหรับเขียนโค้ด, SaaS ให้บริการซอฟต์แวร์สำเร็จรูปพร้อมใช้งาน

[หมวด: Cloud & Database]
Q: Database คืออะไร?
A: คือระบบจัดเก็บข้อมูลอย่างเป็นระเบียบในคอมพิวเตอร์ เพื่อให้สามารถค้นหา จัดการ อัปเดต และดึงข้อมูลมาใช้งานได้อย่างมีประสิทธิภาพ

[หมวด: Cloud & Database]
Q: Relational Database (RDBMS) ต่างจาก NoSQL อย่างไร?
A: RDBMS เก็บข้อมูลในรูปแบบตารางที่มีความสัมพันธ์ชัดเจน ใช้ SQL (เช่น MySQL, PostgreSQL) ส่วน NoSQL เก็บข้อมูลแบบยืดหยุ่น เช่น JSON/Document (เช่น MongoDB)

[หมวด: Cloud & Database]
Q: SQL คืออะไร?
A: SQL (Structured Query Language) คือภาษามาตรฐานที่ใช้ในการจัดการและสอบถามข้อมูลในระบบฐานข้อมูลเชิงสัมพันธ์

[หมวด: Cloud & Database]
Q: Primary Key ในฐานข้อมูลคืออะไร?
A: คือคอลัมน์ที่ใช้นับเป็นรหัสเฉพาะของแต่ละแถวข้อมูลในตาราง โดยข้อมูลใน Primary Key ห้ามซ้ำกันและห้ามเป็นค่าว่าง (NULL)

[หมวด: Cloud & Database]
Q: Data Backup มีความสำคัญอย่างไร?
A: คือการสำรองข้อมูลไว้ในอีกสถานที่หรือสื่อจัดเก็บอื่น เพื่อป้องกันข้อมูลสูญหายจากฮาร์ดแวร์พัง ภัยธรรมชาติ หรือถูกโจมตีด้วยมัลแวร์

[หมวด: Cloud & Database]
Q: Container เช่น Docker มีประโยชน์อย่างไร?
A: ช่วยจำลองซอฟต์แวร์และสภาพแวดล้อมที่จำเป็นทั้งหมดไว้ในแพ็กเกจเดียว ทำให้รันแอปพลิเคชันได้เหมือนกันทุกเครื่องโดยไม่มีปัญหาความต่างของระบบ

[หมวด: Cloud & Database]
Q: Cloud Storage มีข้อดีอย่างไรเมื่อเทียบกับการเก็บใน Hard Disk?
A: สามารถเข้าถึงข้อมูลได้ทุกที่ทุกเวลาผ่านอินเทอร์เน็ต มีระบบสำรองข้อมูลให้อัตโนมัติ และแชร์ไฟล์ให้ผู้อื่นทำงานร่วมกันได้ง่าย

[หมวด: Cloud & Database]
Q: Serverless Computing คืออะไร?
A: คือรูปแบบที่นักพัฒนาสามารถรันโค้ดได้โดยไม่ต้องคอยดูแลจัดการเซิร์ฟเวอร์เอง ระบบ Cloud จะจัดสรรทรัพยากรและคิดเงินตามเวลาที่โค้ดทำงานจริงเท่านั้น

[หมวด: Cloud & Database]
Q: Database Indexing ช่วยอะไร?
A: ช่วยให้ระบบฐานข้อมูลค้นหาข้อมูลได้รวดเร็วขึ้นมาก โดยสร้างดัชนีชี้ตำแหน่งข้อมูล เหมือนดัชนีท้ายเล่มหนังสือ

[หมวด: Cloud & Database]
Q: Big Data มีลักษณะสำคัญ 3V อะไรบ้าง?
A: ประกอบด้วย Volume (ปริมาณมหาศาล), Velocity (ความเร็วในการเกิดขึ้นของข้อมูล), และ Variety (ความหลากหลายของรูปแบบข้อมูล)

[หมวด: Cloud & Database]
Q: Load Balancer ทำหน้าที่อะไร?
A: ทำหน้าที่กระจายทราฟฟิกของผู้ใช้ไปยังเซิร์ฟเวอร์หลายๆ เครื่อง เพื่อป้องกันไม่ให้เครื่องใดเครื่องหนึ่งทำงานหนักเกินไปและช่วยให้ระบบลื่นไหล

[หมวด: Cloud & Database]
Q: Data Replication คืออะไร?
A: คือการคัดลอกและทำสำเนาข้อมูลจากฐานข้อมูลหนึ่งไปยังอีกฐานข้อมูลหนึ่งแบบเรียลไทม์ เพื่อรองรับความเสถียรและป้องกันระบบล่ม

[หมวด: Cloud & Database]
Q: Public Cloud กับ Private Cloud ต่างกันอย่างไร?
A: Public Cloud แชร์ใช้โครงสร้างพื้นฐานร่วมกับผู้อื่น ค่าใช้จ่ายถูกกว่า ส่วน Private Cloud เป็นระบบคลาวด์ที่สร้างขึ้นใช้เฉพาะภายในองค์กร มีความปลอดภัยและเป็นส่วนตัวสูงกว่า

[หมวด: AI & Innovations]
Q: Artificial Intelligence (AI) คืออะไร?
A: คือเทคโนโลยีการพัฒนาระบบคอมพิวเตอร์ให้มีความสามารถในการเรียนรู้ คิด วิเคราะห์ และแก้ปัญหาได้คล้ายคลึงกับมนุษย์

[หมวด: AI & Innovations]
Q: Machine Learning (ML) ต่างจาก AI อย่างไร?
A: AI เป็นภาพใหญ่ของการสร้างระบบปัญญาประดิษฐ์ ส่วน ML เป็นสาขาหนึ่งของ AI ที่เน้นการให้คอมพิวเตอร์เรียนรู้จากข้อมูลได้ด้วยตนเองโดยไม่ต้องเขียนโปรแกรมสั่งทุกขั้นตอน

[หมวด: AI & Innovations]
Q: Deep Learning คืออะไร?
A: เป็นแขนงย่อยของ Machine Learning ที่ใช้โครงข่ายประสาทเทียมหลายชั้น (Deep Neural Networks) ในการประมวลผลข้อมูลซับซ้อน เช่น ภาพ เสียง หรือข้อความ

[หมวด: AI & Innovations]
Q: Large Language Model (LLM) คืออะไร?
A: คือโมเดล AI ที่ได้รับการฝึกฝนด้วยข้อความมหาศาล จนสามารถเข้าใจ เจนข้อความ แปลภาษา และตอบคำถามได้อย่างเป็นธรรมชาติ เช่น ChatGPT

[หมวด: AI & Innovations]
Q: Internet of Things (IoT) คืออะไร?
A: คือเครือข่ายของอุปกรณ์ต่างๆ ที่ฝังเซ็นเซอร์และซอฟต์แวร์ ให้สามารถเชื่อมต่อและรับส่งข้อมูลระหว่างกันผ่านอินเทอร์เน็ตได้ เช่น หลอดไฟอัจฉริยะ Smartwatch

[หมวด: AI & Innovations]
Q: Blockchain ทำงานอย่างไร?
A: เป็นระบบจัดเก็บข้อมูลแบบกระจายศูนย์ (Decentralized) ข้อมูลถูกบันทึกเป็นบล็อกต่อกันและเข้ารหัสไว้อย่างปลอดภัย ไม่สามารถแก้ไขย้อนหลังได้โดยปราศจากการยินยอม

[หมวด: AI & Innovations]
Q: Generative AI คืออะไร?
A: คือประเภทของ AI ที่เน้นการสร้างสรรค์เนื้อหาใหม่ๆ ขึ้นมา เช่น ข้อความ ภาพ เสียง หรือโค้ดคอมพิวเตอร์ ตามคำสั่ง (Prompt) ที่ได้รับ

[หมวด: AI & Innovations]
Q: Computer Vision คืออะไร?
A: เป็นสาขาของ AI ที่ทำให้คอมพิวเตอร์สามารถมองเห็น เข้าใจ และตีความข้อมูลรูปภาพหรือวิดีโอได้ เช่น ระบบตรวจจับใบหน้า

Q: Natural Language Processing (NLP) คืออะไร?
A: คือสาขาของ AI ที่เน้นทำให้คอมพิวเตอร์เข้าใจ แปลความหมาย และสื่อสารด้วยภาษาของมนุษย์ได้อย่างถูกต้อง

[หมวด: AI & Innovations]
Q: Quantum Computing คืออะไร?
A: คือเทคโนโลยีคอมพิวเตอร์ยุคใหม่ที่ใช้หลักการทางควันตัม (Qubits) ทำให้ประมวลผลโจทย์ซับซ้อนได้เร็วกว่าซูเปอร์คอมพิวเตอร์แบบดั้งเดิมมหาศาล

[หมวด: General Knowledge]
Q: Bit กับ Byte ต่างกันอย่างไร?
A: Bit เป็นหน่วยข้อมูลที่เล็กที่สุด (มีค่า 0 หรือ 1) ส่วน 1 Byte ประกอบด้วย 8 Bits (มักใช้แทนตัวอักษร 1 ตัว)

[หมวด: General Knowledge]
Q: 1 Gigabyte (GB) เท่ากับกี่ Megabytes (MB)?
A: ตามระบบฐานสอง 1 GB เท่ากับ 1,024 MB (หรือ 1,000 MB ตามระบบฐานสิบของสเปกผู้ผลิต)

[หมวด: General Knowledge]
Q: Open Source กับ Freeware ต่างกันอย่างไร?
A: Freeware ใช้งานได้ฟรีแต่ไม่อนุญาตให้ดูหรือแก้ไขซอร์สโค้ด ส่วน Open Source เปิดให้ดู แก้ไข และนำโค้ดไปพัฒนาต่อได้อย่างอิสระ

[หมวด: General Knowledge]
Q: โปรเซสเซอร์ 64-bit สามารถใส่ RAM ได้สูงสุดเท่าไหร่?
A: ในทางทฤษฎีระบบ 64-bit สามารถรองรับ RAM ได้สูงสุดถึง 16 Exabytes (EB) ซึ่งเกินพอสำหรับการใช้งานในปัจจุบัน

[หมวด: General Knowledge]
Q: Cookie ในเว็บเบราว์เซอร์คืออะไร?
A: คือไฟล์ข้อความขนาดเล็กที่เว็บไซต์บันทึกไว้ในเครื่องของผู้ใช้ เพื่อจดจำข้อมูลการเข้าชม สถานะログイン หรือการตั้งค่าต่างๆ

[หมวด: General Knowledge]
Q: GPU ประมวลผลได้ดีกว่า CPU ในงานประเภทใด?
A: GPU ทำงานคำนวณแบบขนาน (Parallel Processing) ได้ดีกว่า เหมาะสำหรับงานประมวลผลกราฟิก ตัดต่อวิดีโอ 3D และการฝึกฝนโมเดล AI

[หมวด: General Knowledge]
Q: ดับเบิลคลิกไฟล์ .exe บน Windows หมายถึงอะไร?
A: คือการสั่งรันโปรแกรมหรือแอปพลิเคชันที่เป็นไฟล์การทำงานหลัก (Executable File) บนระบบปฏิบัติการ Windows

[หมวด: General Knowledge]
Q: IP Address แบบ Static กับ Dynamic ต่างกันอย่างไร?
A: Static IP เป็นหมายเลขคงที่ไม่เปลี่ยนแปลง เหมาะกับเซิร์ฟเวอร์ ส่วน Dynamic IP จะเปลี่ยนไปเรื่อยๆ ตามการจัดสรรของ ISP/DHCP

[หมวด: General Knowledge]
Q: คำว่า Debugging หมายถึงอะไร?
A: คือกระบวนการค้นหา วิเคราะห์ และแก้ไขข้อผิดพลาด (Bug) ที่เกิดขึ้นในซอฟต์แวร์หรือโค้ดโปรแกรม

[หมวด: General Knowledge]
Q: ASCII และ Unicode ต่างกันอย่างไร?
A: ASCII ใช้รหัสขนาดเล็กสำหรับตัวอักษรภาษาอังกฤษและสัญลักษณ์พื้นฐาน ส่วน Unicode เป็นมาตรฐานรหัสที่รองรับตัวอักษรของทุกภาษาทั่วโลกรวมถึงภาษาไทยและอีโมจิ

[หมวด: General Knowledge]
Q: Command Line Interface (CLI) ต่างจาก GUI อย่างไร?
A: CLI ป้อนคำสั่งด้วยการพิมพ์ข้อความผ่านเทอร์มินัล ส่วน GUI (Graphical User Interface) ใช้งานผ่านองค์ประกอบภาพ เช่น ปุ่ม ไอคอน และเมาส์

[หมวด: General Knowledge]
Q: การทำ Overclocking คืออะไร?
A: คือการปรับเพิ่มความถี่สัญญาณนาฬิกาของ CPU หรือ GPU ให้ทำงานสูงกว่าค่ามาตรฐานเพื่อเพิ่มความเร็ว แต่จะทำให้เกิดความร้อนสูงขึ้นและใช้พลังงานมากขึ้น

[หมวด: General Knowledge]
Q: เครือข่าย LAN, MAN และ WAN ต่างกันอย่างไร?
A: LAN เป็นเครือข่ายระยะใกล้ (ในบ้าน/ออฟฟิศ), MAN เป็นเครือข่ายระดับเมือง, ส่วน WAN เป็นเครือข่ายระยะไกลระดับประเทศหรือข้ามโลก เช่น อินเทอร์เน็ต

[หมวด: General Knowledge]
Q: โปรโตคอล (Protocol) คืออะไร?
A: คือกฎระเบียบ ข้อบังคับ หรือมาตรฐานที่ใช้อธิบายวิธีการสื่อสารและรับส่งข้อมูลระหว่างอุปกรณ์ในระบบเครือข่าย

[หมวด: General Knowledge]
Q: Cache บนเว็บเบราว์เซอร์มีไว้เพื่ออะไร?
A: ใช้เก็บไฟล์รูปภาพหรือสคริปต์ของเว็บไซต์ไว้ชั่วคราว เพื่อให้การเปิดเว็บเดิมในครั้งถัดไปทำได้เร็วขึ้นโดยไม่ต้องโหลดข้อมูลใหม่ทั้งหมด
